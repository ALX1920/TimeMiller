# 🔄 Actualización 2026

## Bugs corregidos

- `script.js` intentaba actualizar `#start-date`, `#current-date` e
  `#info-text`, pero esos elementos no existían (o tenían un `id` inválido
  con espacio) en el HTML. Se corrigió el HTML y el JS para que coincidan.
- `footer.css` existía pero nunca se importaba desde `main.css`.
- Estilos inline duplicados en el footer del `index.html`.
- La animación de color sobre todo el texto usaba `-webkit-text-stroke`
  negro como parche de contraste; se reemplazó por un overlay real sobre
  la imagen de fondo.

## Rediseño

- El tiempo ahora se muestra como un panel tipo HUD/telemetría (tiles con
  número grande monoespaciado + etiqueta) en vez de una oración larga.
- Tipografía monoespaciada para números y fechas (sensación de "consola de
  nave"), tipografía del sistema para el resto del texto.
- Una sola animación deliberada (glow del título), respetando
  `prefers-reduced-motion`.
- Mejoras de accesibilidad: skip-link, foco visible, roles/etiquetas ARIA.
- Meta tags: descripción, Open Graph, favicon.

## Nueva funcionalidad: contador de visitas

Se agregó un backend en Django (`/backend`) para llevar la cuenta de
visitantes únicos por día, listo para desplegarse con Docker. El frontend
lo consume vía `fetch` si se configura `VISITS_API_BASE` en `script.js`;
si no se configura, el sitio sigue funcionando igual y el contador
simplemente no se muestra.

Ver [`backend/README.md`](../backend/README.md) para el detalle técnico y
las instrucciones de despliegue.

## Organización de CSS

`main.css` pasó a ser exclusivamente el punto de entrada que importa los
componentes, sin reglas propias. Se agregaron `reloj.css` (los tiles de
tiempo) y `utilidades.css` (accesibilidad/animación).
